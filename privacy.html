Политика конфиденциальности

1. Кто мы

Оператор данных — Попов Матвей Юрьевич, самозанятый, ИНН 231521307407. Связь: см. раздел «Контакты» ниже.

2. Этот сайт

Сайт статический: у него нет аккаунтов, форм, куки, счётчиков посещений, рекламы и сторонней аналитики. Размещён на GitHub Pages; как и любой веб-сервер, GitHub может фиксировать технические данные запроса (IP-адрес, браузер, время) по собственной политике — Получатель к этим данным доступа не имеет.

3. Пожертвования

При пожертвовании обрабатываются: сумма, дата и статус платежа, идентификатор операции, адрес электронной почты, который вы указали для чека. Оплата проходит на стороне платёжного сервиса — номер карты, CVC и имя держателя Получатель не получает и не хранит. Платёжный сервис обрабатывает данные по своей политике.

Для формирования чека сведения о платеже вносятся в приложение «Мой налог» (ФНС России).

4. Зачем и как долго

Данные используются только для приёма платежа, отправки чека, ответа на обращения и выполнения налоговых и бухгалтерских обязанностей. Не продаются и не передаются третьим лицам, кроме платёжного сервиса и ФНС в объёме, нужном для платежа и отчётности. Сведения о платежах хранятся в течение срока налоговой и бухгалтерской отчётности (не менее 4 лет), обращения — пока нужны для решения вопроса.

Вы можете запросить сведения о своих данных, их исправление или удаление, если закон не требует их хранения. Напишите по контактам ниже; ответ — в срок до 10 рабочих дней.

6. Сами проекты

Arsound и моды для RimWorld не отправляют данные Получателю. Что приложение отправляет на сторонние сервисы (например, названия треков и исполнителей в Last.fm для рекомендаций), описано в README проекта; эти функции настраиваются пользователем.
